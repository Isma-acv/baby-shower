# Baby Shower · 22 de noviembre de 2026

Invitación digital animada para el baby shower del domingo 22 de noviembre de 2026 a las 2:45 pm.

## Qué incluye

- Sobre animado que se abre al tocar el sello
- Flor y abejitas en 3D con [Zdog](https://zzz.dog/)
- Animaciones con [Anime.js](https://animejs.com/), [Animate.css](https://animate.style/) y [Magic Animations](https://www.minimamente.com/portfolio/magic/)
- Cuenta regresiva, ubicación, botón para agendar, itinerario y detalles
- Diseño Mobile First

## Estructura

- `index.html`: toda la invitación en un solo archivo (estilos, scripts e imágenes incluidos)

## Publicar con GitHub Pages

1. Sube este proyecto a un repositorio de GitHub.
2. En el repositorio entra a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En uno o dos minutos la invitación queda en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Editar datos

Al inicio del script, en el objeto `CONFIG`, puedes cambiar el nombre de la festejada, el lugar, la dirección y el enlace del mapa.
